# Weather App

Ini adalah aplikasi cuaca sederhana menggunakan Flask.

## Struktur Proyek

weather-app/
│
├── app.py                  # File utama Flask
├── templates/
│   └── index.html          # Template HTML untuk menampilkan data cuaca
|   └── forecast.html
|   └── dashboard.html
|   └── login.html
|   └── register.html
|   └── back.html
└── models.py
└── config.py
└── extensions.py
└── postcss.config.js
└── prettier.config.js
└── tailwind.config.js
└── package.json
└── package-lock.json
└── weather_data.db         # Sebagai Database dengan MySQLite

Cara Menjalankan : 
Clone repository ini.
Install dependensi yang diperlukan.
Jalankan python app.py untuk memulai aplikasi.
